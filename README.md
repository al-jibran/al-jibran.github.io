# Technical Blog

This is the source for my technical blog.

I write about software, things I have learned, and things I am still learning. The blog is mostly a place for me to work through ideas, document what I understand, and connect individual concepts to the larger systems they belong to.

## Site

The site is built with [Astro](https://astro.build/) and deployed with GitHub Pages.

A few implementation details:

- Astro components for the UI
- Markdown content collections for posts
- Tailwind CSS for styling
- RSS and sitemap support

## Development

```sh
npm install
npm run dev
```

Other useful commands:

```sh
npm run build
npm run preview
```
